# ダイアトニック・ドリル

メジャー／ナチュラルマイナー全24キーのダイアトニックコード・度数・構成音を覚えるための Web アプリ。

- **ドリル**：度数→コード／コード→度数／構成音の4択クイズ。苦手なキーを優先出題
- **全一覧**：12キー × 7度数の表（五度圏順／♯系→♭系）。隠してめくる暗記モード、タップで構成音表示
- **覚え方**：コードの型、調号、五度圏、指板上の形をまとめた図入りのカンニングペーパー（キーを選ぶと図が切り替わる）

`index.html` と `theory.js` の 2 枚で動きます（ビルド不要、`file://` で開いても動く）。記録はブラウザの localStorage に保存されます。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面と操作（DOM・保存・描画） |
| `theory.js` | 音楽理論の計算と出題の組み立て。DOM に触らないのでテストできる |
| `test/` | `theory.js` の単体テスト |

## テスト

```sh
npm test   # Node 16 以上。依存パッケージは無い
```
